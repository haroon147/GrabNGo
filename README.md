# Grab N Go

Restaurant website for Grab N Go in Bahria Town, Lahore.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## GitHub Pages deployment

The site is configured for the `haroon147/GrabNGo` project repository. The GitHub Actions workflow builds the Vite site and deploys it to GitHub Pages whenever a commit is pushed to `main`.

In the repository settings, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. After the first successful workflow, the site will be available at:

<https://haroon147.github.io/GrabNGo/>
